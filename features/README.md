# Возможности и роли участников

Во время онлайн-конференции каждому участнику назначается роль. От роли зависит, какие действия доступны человеку в комнате: **управление звуком других участников**, **демонстрация экрана** и **запуск записи**.

## Права участников по ролям

| Роль | Включение своего микрофона и камеры | Управление участниками и залом ожидания | Демонстрация экрана | Запуск и остановка записи |
| --- | --- | --- | --- | --- |
| Организатор | Да | Да | Да | Да |
| Соорганизатор | Да | Да | Да | Да |
| Докладчик | Да | Нет | Да | Нет |
| Участник | По разрешению | Нет | По разрешению | Нет |

Подробнее о том, как сохраняются материалы созвонов, читайте в разделе [«Запись встреч и архив»](recordings/README.md). Если возникли сложности с подключением, перейдите в [FAQ](../faq/README.md).
