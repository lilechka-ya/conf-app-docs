# Запись встреч и архив

Функция записи помогает сохранить важные обсуждения, лекции и созвоны, чтобы вернуться к ним позже или поделиться с теми, кто не смог присутствовать.

## Как записать конференцию

1. Войдите в активную комнату с правами **организатора** или **соорганизатора**.
2. Откройте дополнительное меню в нижней панели управления.
3. Выберите пункт **«Начать запись»** и дождитесь появления индикатора записи.
4. По завершении обсуждения откройте меню снова и нажмите **«Остановить запись»**.

**Важно:** обработка видеозаписи может занимать несколько минут после завершения встречи. Готовые записи появляются в разделе **«История встреч»**, а при нехватке места в облаке обратитесь в [частые вопросы](../../faq/README.md).
