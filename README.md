# Мобильное приложение «Онлайн-конференции»

Добро пожаловать в руководство пользователя мобильного приложения для проведения видеовстреч, вебинаров и рабочих созвонов. С его помощью вы можете **создавать комнаты в пару касаний**, подключаться к встречам по коду или ссылке и управлять участниками прямо со смартфона.

## Основные возможности сервиса

| Функция | Описание | Доступность |
| --- | --- | --- |
| Видео- и аудиосвязь | Общение в реальном времени с автоматическим шумоподавлением | Все пользователи |
| Зал ожидания | Проверка участников организатором перед входом в комнату | Организатор и соорганизатор |
| Демонстрация экрана | Показ презентаций, документов и интерфейса со смартфона | По разрешению организатора |
| Запись конференции | Сохранение видео- и аудиодорожки встречи для дальнейшего просмотра | При активной подписке |
